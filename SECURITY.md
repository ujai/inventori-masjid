# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** on this repository. Include steps to reproduce and the affected version or commit.

You should get a reply within 7 days.

## Scope

In scope: authentication and authorisation bypasses, data exposure between roles, injection, and leaking secrets or personal data.

Each deployment is run by its own mosque. Report issues with a specific deployment to that mosque's administrators.
